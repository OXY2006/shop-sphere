# ShopSphere - Full Stack E-Commerce Platform

## Overview

ShopSphere is a modern, production-ready full-stack e-commerce platform built using the MERN-adjacent ecosystem with Next.js, TypeScript, PostgreSQL, and Prisma.

The project aims to simulate a real-world online shopping platform with customer, seller, and administrator functionalities while following industry-standard software architecture, security practices, and scalable database design.

This project is being developed as a portfolio project to demonstrate full-stack web development skills, backend architecture, authentication, database management, REST APIs, responsive UI design, and deployment.
